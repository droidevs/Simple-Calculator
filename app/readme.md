# Samsung Calculator Clone

A modern Android calculator application inspired by the functionality and user experience of the Samsung Calculator app.

## Status

✅ Stable and fully working

This project is actively maintained and all core calculator features are functional and tested.

## Features

* Basic arithmetic operations

    * Addition
    * Subtraction
    * Multiplication
    * Division

* Advanced operations

    * Percentage
    * Square root
    * Power calculations
    * Parentheses support
    * Decimal operations

* Scientific calculator support

    * Trigonometric functions
    * Logarithmic functions
    * Constants
    * Advanced math expressions

* Responsive and smooth UI

* Real-time expression evaluation

* Expression history

* Error handling

* Landscape scientific mode

* Clean Samsung-inspired design

* Optimized performance

* Material Design support

* Dark mode support

## Tech Stack

* Kotlin
* Jetpack Compose
* Android SDK
* MVVM Architecture
